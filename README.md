## 译文的风格

三条，按先后：

1. **先是通顺的中文。** 每一句都要是合格的中文，病句再贴原文也不要。
2. **再对法文苛求精确。** 信息不增不减，词义不打折扣。
3. **最后求清楚。** 读一遍就懂，不必回头。

### 举个例子（¶682）

> *Il savait que la réalité de circonstances qu’il eût donné sa vie pour restituer exactement, était lisible derrière cette fenêtre striée de lumière, comme sous la couverture enluminée d’or d’un de ces manuscrits précieux…*

- **硬译**：他知道，那些他本会献出自己的生命去精确地恢复的情况的现实，在这扇被光划出条纹的窗户后面是可以阅读的，就像在那些珍贵的手稿之一的被金色装饰的封面之下……
- **定稿**：有些实情，他宁可拿性命去换，只求一丝不差地还原出来；他知道，这些实情此刻就在这扇透出条条灯光的窗子后面，可以读到，就像一部珍贵手抄本描金封面下的文字……

为什么这样改：

- **先立话题**：法文把一长串从句挂在主语上，中文先说出“有些实情”，再一层层往下说。
- **词义要准**：*eût donné sa vie pour* 是夸张的说法，不是“本来会”，所以译“宁可拿性命去换”。
- **少用“的”和“被”**：硬译一句六个“的”、两个“被”，定稿只有两个“的”，没有“被”。

## 制作方法

- **译文**：Claude 起草，我逐段审改。每段读两遍：第一遍不看原文，只当中文读，查病句、指代和画面；第二遍对照法文，查信息、虚词和语气。两遍都过了，才算定稿。
- **注释**：挂在法文词句上，一条注说清一件事：难懂的语法，全书前后的照应，人物地名，历史和艺术。由 Claude 撰写，再交独立的一轮核查，逐条按出处和法文核对。注分三组：文字（原文、句法、语法）、书（回响、人物、地方）、世界（历史、文学、艺术、音乐、饮食、自然）。
- **图版**：为原文配同时代的画作和插图，每幅先说明它和原文是什么关系。只用已进入公有领域的作品。
- **原文**：法文据公有领域版本，按全书段号（¶）编排，便于引用和对照。
